# ✨ Lumina – Image Gallery

Lumina is a modern, elegant image gallery designed to showcase beautiful images in a clean and visually appealing interface.

🌐 **Live Demo:** [View Lumina](https://itsmahimap-codes.github.io/LUMINA-IMAGE-GALLERY/)

---

## 📌 About the Project

**Lumina Image Gallery** is a responsive web project created to provide a simple and engaging way to explore and view a collection of images.

The project focuses on:

- 🎨 Clean and modern UI
- 🖼️ Beautiful image presentation
- 📱 Responsive design
- ⚡ Smooth and interactive user experience
- 🌐 Easy access through a deployed web link

---

## 🚀 Features

- 🖼️ Image gallery layout
- 🔍 Easy image browsing
- 📱 Responsive design for different screen sizes
- ✨ Modern and minimal interface
- ⚡ Lightweight and fast
- 🌐 Deployed using GitHub Pages

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the website
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactivity and functionality
- **GitHub Pages** – Deployment
